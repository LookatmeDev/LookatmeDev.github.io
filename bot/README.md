# Бот-портфолио

Бот @AXIdesign_bot. На `/start` присылает приветствие и кнопку «Открыть портфолио», которая открывает сайт как Telegram Mini App. Кнопка меню рядом с полем ввода делает то же самое.

## Запуск

1. Создайте бота в @BotFather, скопируйте токен.
2. `cp .env.example .env` и вставьте токен в `BOT_TOKEN`.
3. `npm install`
4. `npm start`

Бот работает через long polling, поэтому процесс должен быть запущен постоянно (VPS, Railway, Fly.io и т. п.). Токен хранится только в `.env`, файл не попадает в git.

## Что настроить в @BotFather (по желанию)

- `/setdescription`: короткое описание в пустом чате с ботом.
- `/setuserpic`: аватар бота.
- `/newapp`: прямая ссылка вида `t.me/AXIdesign_bot/app`. Укажите адрес сайта `https://lookatmedev.github.io/`.
